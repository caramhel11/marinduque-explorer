Marinduque Explorer — Lab Activity #4

Course: Web Systems and Technologies  
  Sector: Tourism & Cultural Innovation

Project idea

Marinduque Explorer is a simple website idea for people who want to browse places and cultural spots around Marinduque. The page puts sample places in one list and lets users save a few places for a possible trip.

Main features

1. Search the sample places.
2. Filter places by category.
3. Add places to a trip list, remove them, or clear the list.

The website uses HTML, CSS, and JavaScript. It has no backend, database, login, or external API. The place descriptions are examples, not live tourism information.
